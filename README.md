# 🌱 AgriBrain

AgriBrain is an AI-powered smart agriculture platform developed to help users analyze plant health through image processing technologies.

## 🚀 Features

- User Registration & Login
- Secure Session Management
- Plant Image Upload
- AI-Based Plant Health Analysis (Prototype)
- Analysis History
- Dashboard
- Health API
- Privacy Policy & KVKK Pages

## 🛠 Technologies

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
- Jinja2

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/AgriBrain.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
cd backend
python app.py
```

Open your browser:

```
http://127.0.0.1:5001
```
